# Annotation Guidelines — LLM Response Quality Evaluation

## Objective
Evaluate a sample of prompt/response pairs generated by a language model and label each on three dimensions to support model quality assessment and training-data curation.

## Dimensions & Scoring (1-5 scale)

**Helpfulness** - Does the response fully address what the user asked?
- 5: Directly and completely answers the request
- 3: Partially answers, missing detail or nuance
- 1: Does not address the request

**Accuracy** - Is the factual/technical content correct?
- 5: Fully correct, no errors
- 3: Mostly correct with a minor error
- 1: Contains a significant factual or logical error

**Clarity** - Is the response well-structured and easy to follow?
- 5: Clear, well-organized, appropriate length
- 3: Understandable but poorly structured or verbose
- 1: Confusing or incoherent

## Flags
- AMBIGUOUS_PROMPT - the prompt itself is unclear enough that multiple valid responses exist
- FACTUAL_ERROR - response contains an identifiable factual mistake
- NEEDS_ESCALATION - response touches a sensitive/safety-relevant area and should be reviewed by a second annotator

## Process
1. Read the prompt and response independently before scoring (avoid anchoring on response length or tone).
2. Score each dimension separately - a confident but wrong answer should score high on Clarity, low on Accuracy.
3. Apply flags where relevant; a single response may carry more than one flag.
4. Record a one-line rationale for any score of 1-2, to support QA review and guideline refinement.
5. Re-check the guideline against your own scores every ~10 items to catch drift.
